# 🚀 iTask – React Todo Application

A modern and responsive task management application built with React and Tailwind CSS. Designed to help users organize, track, and manage daily tasks efficiently through a clean and intuitive interface.

## ✨ Features

* ✅ Add new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ✔️ Mark tasks as completed
* 👀 Show/Hide completed tasks
* 💾 Persistent storage using Local Storage
* 📱 Responsive user interface
* 🔑 Unique task IDs using UUID
